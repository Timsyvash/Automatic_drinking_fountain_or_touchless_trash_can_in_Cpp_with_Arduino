# 🗑️ / 💧 Безконтактний автоматичний смітник / поїлка на Arduino

Автономний проєкт на базі мікроконтролера **Arduino**, інфрачервоного датчика руху **PIR** та сервоприводу **Servo**. 

Пристрій автоматично відкриває кришку смітника або заслонку поїлки при наближенні людини чи тварини, утримує її відкритою визначений час і плавно закриває.

---

## 🚀 Основні можливості

- 🤖 **Повністю безконтактне керування:** Спрацювання від датчика руху (PIR).
- ⚙️ **Плавний механічний привід:** Використання сервоприводу для точності кута відкриття (0°–90°).
- ⏱️ **Автоматичний таймер закриття:** Налаштовувана затримка утримання кришки відкритою (за замовчуванням 5 секунд).
- 🔋 **Низьке енергоспоживання:** Можливість роботи від акумуляторів або батарейного блоку.

---

## 🛠️ Необхідні компоненти

- **Мікроконтролер:** Arduino (Uno / Nano / Pro Mini / Mega)
- **Датчик руху:** PIR HC-SR501 (або мініатюрний AM312)
- **Сервопривід:** Micro Servo SG90 / MG90S (або MG996R для важких кришок)
- **Джерело живлення:** 5V (USB-кабель, блок живлення або акумулятори 18650 з підвищувальним модулем)
- **Допоміжні деталі:** Соединительные провода (Dupont), макетна плата або пайка

---

## 🔌 Схема підключення (Pinout)

| Компонент | Пін компонента | Пін Arduino | Примітка |
| :--- | :--- | :--- | :--- |
| **PIR Sensor** | VCC | **5V** | Живлення датчика |
| | GND | **GND** | Спільне заземлення |
| | OUT (Signal) | **Pin 2** | Цифровий вхід руху |
| **Сервопривід (Servo)** | VCC (Червоний) | **5V** | Окреме живлення при потужному серво |
| | GND (Коричневий/Чорний)| **GND** | Спільне заземлення |
| | Signal (Жовтий/Помаранчевий) | **Pin 9** (PWM) | Керування кутом |

> ⚠️ **Порада:** Якщо ви використовуєте потужний сервопривід (наприклад, MG996R), підключіть його живлення VCC до окремого джерела 5V (зі спільним GND), щоб уникнути перезавантаження Arduino від просідання напруги.

## 💻 Програмний код (C++)

Проєкт використовує стандартну бібліотеку `<Servo.h>`.

```cpp
#include <Arduino.h>
#include <Servo.h>

// --- ПІНИ ПІДКЛЮЧЕННЯ ---
const int PIR_PIN = 2;     // Сигнальний пін PIR датчика
const int SERVO_PIN = 9;   // Пін керування сервоприводом

// --- НАЛАШТУВАННЯ МЕХАНІЗМУ ---
const int CLOSED_ANGLE = 0;   // Кут закритого стану (градуси)
const int OPEN_ANGLE = 90;    // Кут відкритого стану (градуси)
const unsigned long HOLD_TIME = 5000; // Час утримання відкритим (5000 мс = 5 сек)

Servo lidServo;

void setup() {
  pinMode(PIR_PIN, INPUT);
  
  lidServo.attach(SERVO_PIN);
  lidServo.write(CLOSED_ANGLE); // Початковий стан — закрито
}

void loop() {
  // Перевіряємо спрацювання датчика руху
  if (digitalRead(PIR_PIN) == HIGH) {
    lidServo.write(OPEN_ANGLE); // Відкриваємо кришку
    delay(HOLD_TIME);           // Чекаємо заданий час

    lidServo.write(CLOSED_ANGLE); // Закриваємо кришку
    delay(1500); // Затримка проти повторного негайного спрацювання
  }
}

⚙️ Механіка та калібрування
1. Встановлення нуля сервоприводу: Перед затисканням важеля (качалки) сервоприводу завантажте код і переконайтеся, що серво встановився в кут 0° (стан CLOSED). Після цього зафіксуйте кришку в закритому положенні.
2. Налаштування кута відкриття: Якщо кришка відкривається занадто сильно або заклинює, змініть значення змінної OPEN_ANGLE у коді (наприклад, з 90 на 70 або 100).
3. Налаштування HC-SR501:
    Відрегулюйте потенціометри на датчику: Чудовість (Sensitivity) встановіть на мінімум (~2-3 метри), щоб кришка не відкривалася від випадкового руху здалеку.
    Таймаут (Delay) встановіть на мінімум.
